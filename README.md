# AC Livery

Редактор и генератор ливрей для **Assetto Corsa**: векторные винилы в духе Forza/GT7, универсальные шаблоны, которые ложатся на любую машину через 3D-проекцию, и массовая генерация скинов для лиги.

> Статус: ранняя разработка. Готово ядро (этап 1): программа читает машины из игры, показывает их в 3D, переключает стоковые скины, перекрашивает кузов в один цвет с сохранением теней и деталей из стока и записывает готовый скин в игру. Редактор винилов появится на этапе 2. План целиком: [docs/SPEC.md](docs/SPEC.md).

_English: a livery editor/generator for Assetto Corsa. Early development; see the spec (in Russian) for the roadmap._

## Возможности этапа 1

- Автоматический поиск папки игры через Steam (или ручной выбор).
- Список машин из `content/cars`: стоковые и моды без шифрования.
- 3D-просмотр модели `.kn5` с приближённой эмуляцией шейдеров AC (`ksPerPixel`, `ksPerPixelMultiMap`, `txMaps`, френель), орбитальная камера и ортогональные виды: бок Л/П, верх, перед, зад.
- Переключение стоковых скинов.
- Анализ машины:
  - какая текстура несёт ливрею и какая карта материалов к ней относится;
  - оси машины по колёсам `WHEEL_*`;
  - предупреждение, если левый и правый борт делят одну область текстуры.
- Новая ливрея: основной цвет плюс тени, стыки панелей и решётки, извлечённые из самого «чистого» стокового скина. Сила эффекта регулируется.
- Сохранение в игру: DDS (через `texconv.exe`, BC1/BC3 с мипмапами), `ui_skin.json`, `preview.jpg`, `livery.png`. Созданные программой скины помечаются маркером `.aclivery.json`: их можно открыть на редактирование, и чужие папки без подтверждения не перезаписываются.
- Интерфейс на русском и английском.

## Разработка

Нужен Node.js 22+.

```bash
npm install
npm run dev          # приложение Electron с hot reload
npm run dev:web      # только интерфейс в браузере с тестовой машиной (без игры и Electron)
npm test             # модульные тесты (Vitest)
npm run lint && npm run typecheck
npm run fetch:texconv  # скачать texconv.exe в resources/bin (для сборки под Windows)
npm run dist         # собрать инсталлятор и portable-версию для Windows
```

Модели Kunos нельзя класть в публичный репозиторий, поэтому тесты и браузерный режим используют синтетическую машину (`src/shared/fixtures/syntheticCar.ts`), сгенерированную в настоящем формате `.kn5`.

### Структура

```
src/
  main/       Electron main: поиск игры, чтение машин, протокол acl://, запись скинов
  preload/    мост IPC для renderer
  shared/     чистый TypeScript без зависимостей от окружения
    formats/  kn5, DDS, ui_skin.json, VDF, JSON с поблажками
    car/      анализ модели (оси, текстура ливреи, развёртка)
    image/    извлечение AO из стокового скина
  renderer/   React-интерфейс и 3D-движок (Three.js)
    engine/   вьюер, шейдеры AC, запекание в UV, воркеры
```
